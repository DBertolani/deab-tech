# Favicon da DEAB Tech

Coloque aqui os arquivos do favicon.

## Arquivos usados atualmente

- `favicon-48.png` — 48x48 px ou maior, formato PNG quadrado.
- `apple-touch-icon.png` — 180x180 px, formato PNG quadrado.

## Recomendação

Use o símbolo da marca DEAB Tech em uma composição simples e legível em tamanho pequeno.

O Google recomenda favicon quadrado e maior que 48x48 px quando possível. O arquivo precisa estar acessível aos robôs de rastreamento.

Fonte: Google Search Central — Favicon nos resultados da Pesquisa.
